# Lab 4 Reflection

## 1. Which acceptance criterion caught something the agent's own report said was done?

Some acceptance criteria I made caught things my agent's own report said were done, such as the photo-to-calories section. I made sure there was a failsafe for when the uploaded photo wasn't actually food. I made it so the app responds with an "uh-oh" message saying you need to upload something else. Furthermore, in the customized plan area, the plan is only the weekly budget, so it is only partially completed, because I intend this to be more of a long-term thing. Although my agent said it was completed, there needs to be a way to display long-term progress and long-term commitment. This might mean adding more filters to my graph.

## 2. What did the three mockups show you that you would not have thought of with one?

Each mockup was useful because it showed me some directions I wasn't quite aware of when I was originally designing what the app should be. I went against my agent's recommendation because I realized my vision wasn't exactly what the agent was expecting or recommending for me. I think I chose the best option, because I believe it is the most user-friendly. That said, it also made me think about the user experience more, because it provided a couple of different views that I didn't quite realize.

## 3. What did the usability test reveal that you could not see yourself? What did you change?

The usability test was helpful because I was able to see the user experience from someone who hasn't been working with the app. It was a completely blind perspective on the application. I was able to see which features were user-friendly and intuitive, and which features were hard to pick up the first time without me saying anything. I was able to change a couple of things from this, such as text not showing up when a phone is on dark mode, and the display of some buttons that weren't lining up visually. I'll continue to make the app a little more visually appealing in the future and potentially ask more people to test my app to find more issues.
